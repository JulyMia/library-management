# 图书馆管理系统

## 项目简介

这是一个基于 Python 3.11 的命令行版图书馆管理系统，用于模拟软件工程实验中的基础业务流程，包括图书管理、用户管理、借阅归还、逾期检查、统计信息和 JSON 本地持久化。

本项目刻意保留了部分 AI 初始生成代码常见问题，例如函数偏长、重复校验逻辑、部分命名较宽泛、职责划分不够干净等，适合作为“AI 生成代码的可读性与可修改性评估与重构”实验对象。

## 功能说明

- 图书管理：添加、删除、修改、查询、显示、库存维护
- 用户管理：添加、删除、修改、查询、显示，支持普通用户、教师用户、管理员
- 借阅管理：借书、还书、库存检查、用户检查、图书检查、借阅记录查询
- 逾期管理：默认借阅天数、逾期判断、逾期天数计算、逾期记录输出
- 数据持久化：使用 `books.json`、`users.json`、`records.json` 自动保存和加载
- 命令行菜单：主菜单与多个子菜单，用户通过输入数字执行操作

## 运行方式

1. 确认 Python 版本为 3.11 或更高版本。
2. 进入项目目录：

```bash
cd library_system
```

1. 首次可导入样例数据：

```bash
python sample_data.py
```

1. 启动系统：

```bash
python main.py
```

## 适合作为重构实验的原因

- `services.py` 中存在较重的业务函数，适合拆分职责
- `main.py` 中菜单函数较长，适合提取公共流程
- 一些变量命名如 `data`、`temp`、`flag`、`result` 不够清晰
- 用户和图书存在性检查在多处重复
- 边界条件处理只做了基础版本
- 错误处理较简单，适合补充异常体系
- 可以进一步引入更清晰的分层和接口设计
- 便于使用 Pylint、Radon、CodeQL 做前后对比分析
